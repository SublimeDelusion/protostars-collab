# Protostars collaboration board

FTC Team 17097’s robot debrief board.

GitHub Pages serves the static frontend from `main` → `/docs`. In **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/docs**, then save.

The frontend uses the existing hosted board API and database. Team members open the Pages link and paste their existing team invite link. The repo does not contain invite keys, board data, or deployment secrets.

To rebuild the frontend, run `npm install` and `npm run build`. The supplied logo is in `docs/protostars.jpg`.
